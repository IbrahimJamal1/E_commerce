تمام، ده **الترتيب الصح من الصفر** لربط Firebase بمشروع Flutter باستخدام **FlutterFire CLI**:

### 1️⃣ تثبيت Firebase CLI

```bash
npm install -g firebase-tools
```

ثم:

```bash
firebase --version
```

---

### 2️⃣ تسجيل الدخول إلى Firebase

```bash
firebase login
```

سجّل الدخول بحساب Google بتاعك.

---

### 3️⃣ تثبيت FlutterFire CLI

```bash
dart pub global activate flutterfire_cli
```

ثم تأكد:

```bash
flutterfire --version
```

---

### 4️⃣ ادخل مشروع Flutter

مثلاً:

```bash
cd D:\flutter\projects\e_commerce
```

وتأكد إنك في المكان اللي فيه:

```text
pubspec.yaml
```

---

### 5️⃣ اربط Flutter بـ Firebase

```bash
flutterfire configure
```

اختار:

```text
Firebase Project
        ↓
مشروعك
        ↓
Android
```

بعدها هيتم إنشاء:

```text
lib/firebase_options.dart
```

---

### 6️⃣ أضف Firebase Core

```bash
flutter pub add firebase_core
```

---

### 7️⃣ عدّل `main.dart`

```dart
import 'package:firebase_core/firebase_core.dart';
import 'package:flutter/material.dart';

import 'firebase_options.dart';

void main() async {
  WidgetsFlutterBinding.ensureInitialized();

  await Firebase.initializeApp(
    options: DefaultFirebaseOptions.currentPlatform,
  );

  runApp(const MyApp());
}
```

---

### 8️⃣ نظف وشغل المشروع

```bash
flutter clean
```

```bash
flutter pub get
```

```bash
flutter run
```

---

### 9️⃣ بعد نجاح الربط

تقدر تضيف الخدمات اللي محتاجها:

**Authentication:**

```bash
flutter pub add firebase_auth
```

**Firestore:**

```bash
flutter pub add cloud_firestore
```

**Storage:**

```bash
flutter pub add firebase_storage
```

**Image Picker:**

```bash
flutter pub add image_picker
```

### 🔥 الشكل النهائي

```text
Firebase
   ↑
   │
flutterfire configure
   │
   ↓
Flutter Project
   │
   ├── firebase_options.dart
   │
   ├── Firebase Auth
   ├── Firestore
   └── Firebase Storage
```

**بالنسبة لـ `google-services.json`: خليه حاليًا، ومتـمسحوش.** بعد ما نتأكد من نجاح `flutterfire configure` وتشغيل التطبيق، نحدد هل نحتاجه في إعداد Android عندك أم لا.
